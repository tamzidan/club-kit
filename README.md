## Ringkasan Cepat

### 1. Masukkan License Key

Masukkan **License Key** kamu pada:

```text
ServerStorage
└── TZKit
    └── ServerSettings
```

### 2. Konfigurasi Fitur

Semua pengaturan yang aman untuk diedit tersedia di:

```text
ServerStorage
└── TZKit
    └── Packages
        └── <Nama Fitur>
            └── Config
```

Disarankan untuk mengubah pengaturan melalui file **`Config`** yang telah disediakan.

### 3. Mengatur Warna dan Tampilan

Seluruh pengaturan warna dan tampilan utama Kit berada di:

```text
ReplicatedStorage
└── TZKit
    └── Settings
        └── Theme
```

Dengan demikian, kamu dapat menyesuaikan tampilan Kit tanpa perlu mengubah kode inti fitur.

### 4. Menjalankan Setup Check

Tekan **Play** di Roblox Studio, kemudian buka **Output** atau tekan:

```text
F9
```

Cari pesan:

```text
[TZKit:SetupCheck]
```

Setup Check akan membantu menampilkan konfigurasi yang masih perlu diisi, seperti:

* Game Pass ID
* Developer Product ID
* Konfigurasi fitur yang belum lengkap
* Pengaturan wajib lainnya

# Ketentuan Lisensi

**TZ Club Kit** dilisensikan untuk **akun/grup yang terdaftar pada License Key** kamu.

Dengan menggunakan Kit ini, kamu menyetujui **EULA (End User License Agreement)** yang ada disini.

Bagian di bawah merupakan ringkasan ketentuan utama dan bukan pengganti EULA lengkap.

## Dilarang

Pengguna dilarang:

* Menjual kembali atau membagikan (*reshare*) Kit ini kepada pihak lain.
* Mempublikasikan Kit ini atau sebagian komponennya sebagai **Model Publik / Free Model**.
* Membongkar (*reverse-engineer*) bagian kode yang dilindungi.
* Menghapus atau menyamarkan pemberitahuan lisensi yang terdapat pada file terbuka Kit.
* Mengklaim Kit ini sebagai karya asli milik sendiri.

## Yang Diperbolehkan

Kamu diperbolehkan untuk:

* Mengubah konfigurasi melalui file `Config`.
* Mengubah warna dan tampilan melalui `Theme`.
* Menambahkan fitur buatan sendiri di atas TZ Club Kit.
* Menyesuaikan Kit untuk kebutuhan game yang menggunakan License Key kamu.

> **Catatan:** Perubahan dan penambahan tersebut tidak memberikan hak untuk menjual kembali, membagikan, atau mendistribusikan TZ Club Kit kepada pihak lain.
